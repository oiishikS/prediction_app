## Frontend (MVP)

This frontend is a lightweight [Next.js](https://nextjs.org) app built for mobile-first usage in the Fun Prediction App.

### Tech choices

- Next.js App Router
- React
- Tailwind CSS (utility-first, lightweight styling)
- HyperUI-style, ready-to-use UI patterns for fast MVP delivery

### Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

### Current scope

- Landing screen
- Quick prediction input
- Upcoming matches list
- Friends leaderboard card

All screens are intentionally simple so the product can ship fast and iterate quickly.
